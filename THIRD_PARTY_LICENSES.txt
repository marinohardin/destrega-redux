Compiler runtime (Windows build only)
----------------------------------------------------------
The Windows executable cross-built with MinGW-w64 GCC links the GCC runtime library (libgcc)
and the winpthreads library statically.

- libgcc: GPL-3.0-or-later WITH the GCC Runtime Library Exception 3.1, which permits linking
  it into programs under any licence. https://gcc.gnu.org/onlinedocs/libstdc++/manual/license.html
- winpthreads / mingw-w64 runtime: MIT-style licence of the mingw-w64 project
  (Copyright (c) 2011 mingw-w64 project). https://www.mingw-w64.org/

Builds made with MSYS2 CLANG64 instead link LLVM's compiler runtime (Apache-2.0 WITH
LLVM-exception) and the Universal C Runtime of Windows.


Not bundled
----------------------------------------------------------
A Vulkan loader / driver (including MoltenVK on macOS, Mesa on Linux) is used only if the
computer already has one; it is not part of this package.
